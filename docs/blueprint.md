# **App Name**: InviteAI VBDA

## Core Features:

- Web Dashboard: Dashboard for uploading CSV data, managing email templates, scheduling emails, and viewing analytics.
- AI Personalization: AI tool to generate personalized email content based on recipient data. The tool will create attention-grabbing hooks that mention the recipient's recent achievements.
- Email Automation: Automated sending of invitation and follow-up emails with triggers based on recipient responses. Integrate with SendGrid or similar for bulk delivery.

## Style Guidelines:

- Primary color: Deep blue (#00308F) to represent trust and authority.
- Secondary color: Light grey (#F5F5F5) for clean and professional backgrounds.
- Accent: Saffron (#FF9933), inspired by the Indian flag, to highlight key actions and information.
- Clean, card-based layout for displaying recipient data and email previews.
- Use clear and professional icons for actions such as upload, send, and view analytics.
